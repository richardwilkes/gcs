# Character Points

The **Points block** keeps a running total of your character points ([B10](B10)). It automatically tracks changes from
attributes, traits, skills, spells, and other entries when you update your [character
sheet](Character%20Sheet%20Overview).

The **Points block toolbar** gives you quick access to common actions used below.

## Changing your starting points

When you create a new character sheet, GCS applies a default number of starting points. You can change the default in
[General Settings](General%20Settings).

To change your starting points for your current sheet:

1. On the **Points block**, select **Edit points** ![edit](images/icons/icn-edit.svg) to open the Points Record.
2. Change the points of the entry whose reason is _Initial points_.
3. On the tab toolbar, select **Apply Changes** ![apply changes](images/icons/icn-applyChanges.svg) to save and close.

## Tracking bonus points

You can also record bonus points ([B498](B498)) your GM awards during play.

To add bonus points:

1. On the **Points block**, select **Edit points** ![edit](images/icons/icn-edit.svg).
2. Select **Add Entry** ![add](images/icons/icn-add.svg) to create a new point entry.
3. Enter the **point value** (decimals are allowed for partial awards) and the **reason**.
4. Select **Apply Changes** ![apply changes](images/icons/icn-applyChanges.svg).

## Managing point entries

- **Date:** Automatically filled when you add an entry. If you edit it, use the format `Aug 23, 2025 2:35 PM`.
- **Discard changes:** Select **Discard Changes** ![discard changes](images/icons/icn-discardChanges.svg) to cancel
  adding points.
- **Delete an entry:** Select **Remove Entry** ![delete](images/icons/icn-delete.svg).
- **Copy to another character sheet:** Select **Copy to Other Character Sheet** ![apply
  template](images/icons/icn-applyTemplate.svg). If multiple sheets are opened, you'll be prompted to choose.
